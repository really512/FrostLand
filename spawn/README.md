# FrostLand Spawn

Главный спавн FrostLand: снежная крепость, вокруг которой проходят основные события сервера.

## Планировка

- Центральная площадь — точка появления игроков.
- Большой замок FrostLand — главный визуальный ориентир и место событий.
- Тронный зал — церемонии, объявления и важные события.
- Ворота замка — главный вход с дорогой от спавна.
- Башни по углам — декоративные обзорные башни.
- Аллея событий — площадка для временных мероприятий.
- Информационная зона — правила, новости и полезные NPC/стенды.
- Площадка порталов — будущие миры и режимы.
- Фонари, ели, снежные сугробы, флаги FrostLand и ледяные декоративные элементы.

## Стиль

Северное средневековое королевство: каменный замок, тёмное дерево, снег, лёд и голубые акценты FrostLand.

## Координаты

Центр спавна: 0 64 0.

Замок занимает центральную северную часть площади. Игрок появляется лицом к главным воротам.

## Важно

Файл frostland_spawn.mcfunction содержит командный черновик строительства. Перед подключением к серверу команды нужно проверить на PowerNukkitX 2.0.0.
