# FrostLand

FrostLand — Minecraft Bedrock server based on PowerNukkitX 2.0.0.

## Structure

- `server/` — server files and runtime data
- `plugins/` — PowerNukkitX plugins
- `config/` — FrostLand configuration

## Version

- PowerNukkitX: 2.0.0
- Platform: Minecraft Bedrock

## Status

🚧 Server is under development.
